Suggested Study Order

Read the runtime in expanding circles: start with one small moving part, then widen the scope.

1. Playground Learn the smallest dynamic loops first: advice chain and request dispatch.
2. Container Lab Understand where beans come from and how the runtime is assembled before requests happen.
3. Example Flow Lab Trace one realistic user request through web, service, transaction, and JDBC layers.
4. Comparison Dashboard Map the simplified learning model onto real Spring Boot architecture and automation.
